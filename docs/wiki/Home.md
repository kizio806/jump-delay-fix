# Jump Delay Fix Wiki

Welcome to the **Jump Delay Fix** wiki.

Jump Delay Fix is a lightweight client-side mod for Minecraft that removes the artificial delay in jump cooldown logic and provides smarter, server-aware jumping behavior.

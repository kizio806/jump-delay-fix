# Installation and Compatibility

## Requirements

- Minecraft Java Edition 26.3
- Java 25 (bundled with the official Minecraft launcher)
- Fabric Loader or NeoForge

## Supported Versions

| Loader    | Minecraft     |
|-----------|---------------|
| Fabric    | 26.3          |
| NeoForge  | 26.3          |

## Installation

### Fabric

1. Install [Fabric Loader](https://fabricmc.net/use/) (>= 0.18.4) for Minecraft 26.3.
2. Install [Fabric API](https://modrinth.com/mod/fabric-api) for Minecraft 26.3.
3. Download `jumpdelayfix-fabric-26.3-1.4.1.jar` from [Modrinth](https://modrinth.com/mod/jump-delay-fix) or [GitHub Releases](https://github.com/kizio806/jump-delay-fix/releases).
4. Place the JAR in your `.minecraft/mods` folder.

### NeoForge

1. Install [NeoForge](https://neoforged.net/) (>= 26.3.0.1-beta) for Minecraft 26.3.
2. Download `jumpdelayfix-neoforge-26.3-1.4.1.jar` from [Modrinth](https://modrinth.com/mod/jump-delay-fix) or [GitHub Releases](https://github.com/kizio806/jump-delay-fix/releases).
3. Place the JAR in your `.minecraft/mods` folder.

## Optional Dependencies

- [ModMenu](https://modrinth.com/mod/modmenu) (Fabric only) — enables the in-game settings screen from the mods list.

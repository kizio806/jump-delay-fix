# Support Policy

Thank you for using **Jump Delay Fix**. This document provides guidelines on how to get assistance, report bugs, ask compatibility questions, and engage with the maintainers.

---

## 📖 Getting Help

Before opening an issue, please consult the documentation:
- [Installation Guide](docs/installation.md) — Loader installation (Fabric & NeoForge), dependencies, and version matrix.
- [Troubleshooting](docs/troubleshooting.md) — Conflict resolution, server anticheat sensitivity, and keybindings.
- [Architecture Guide](docs/architecture.md) — Module separation, client tick listeners, and state flow.
- [Wiki Documentation](docs/wiki/Home.md) — Comprehensive user guides, compatibility charts, and development practices.

---

## 💬 Communication Channels

### 1. GitHub Issues
GitHub Issues are reserved for:
- **Bug Reports:** In-game movement anomalies, unintended behaviors, or incompatibility with specific client environments.
- **Feature Requests:** Configuration options, GUI refinements, or keybinding improvements.
- **Compatibility Reports:** Verifications or issues observed on specific modpacks or server environments.

Please use the appropriate [Issue Template](.github/ISSUE_TEMPLATE) when submitting tickets.

### 2. Security Vulnerabilities
If you identify a security or client-safety issue, please review our [Security Policy](SECURITY.md) and submit a report privately via [GitHub Security Advisories](https://github.com/kizio806/jump-delay-fix/security) rather than using public issues.

### 3. Community Discussions
For gameplay discussions, modpack recommendations, or general help, visit our [GitHub Discussions](https://github.com/kizio806/jump-delay-fix/discussions).

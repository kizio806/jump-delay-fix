# Support Policy

Thank you for using **Jump Delay Fix**. This document provides guidelines on how to get assistance, report bugs, ask compatibility questions, and engage with the maintainers.

---

## Getting Help

Before opening an issue, please consult the documentation:
- [Installation Guide](docs/installation.md) — Loader installation (Fabric & NeoForge), dependencies, and version matrix.
- [Troubleshooting](docs/troubleshooting.md) — Conflict resolution, server anticheat sensitivity, and keybindings.
- [Architecture Guide](docs/architecture.md) — Loader abstraction, Mixin injection points, and state flow.
- [Wiki Documentation](docs/wiki/Home.md) — Comprehensive user guides, compatibility charts, and development practices.

---

## Communication Channels

### 1. GitHub Issues
GitHub Issues are reserved for:
- **Bug Reports:** In-game movement anomalies, incompatibility with specific mods, or Mixin injection failures.
- **Feature Requests:** Config options, GUI refinements, or keybinding improvements.
- **Compatibility Reports:** Verifications or issues observed on specific modpacks or Minecraft versions.

Please use the appropriate [Issue Template](.github/ISSUE_TEMPLATE) when submitting tickets.

### 2. Security Vulnerabilities
If you identify a security or client-safety issue, please review our [Security Policy](SECURITY.md) and submit a report privately rather than using public issues.

### 3. Community Discussions
For gameplay discussions, modpack recommendations, or general help, visit our [GitHub Discussions](https://github.com/kizio806/jump-delay-fix/discussions).

## Supported Versions Matrix

Active bugfixes and patch releases are supported across our multi-version branches:
- **Minecraft 26.3:** `main` branch
- **Minecraft 26.2:** `support/26.2.x` branch
- **Minecraft 26.1.x:** `support/26.1.x` branch
- **Minecraft 1.21.9–1.21.11:** `support/1.21.9-1.21.11` branch
- **Minecraft 1.21.0–1.21.8:** `support/1.21.0-1.21.8` branch
